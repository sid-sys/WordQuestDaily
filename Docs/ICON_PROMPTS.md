# Icon prompts for ChatGPT (image 2, medium quality) - 3 big sheets

Only 3 images are needed (one per day if you have a daily limit). Do them in order: Sheet 1 is the most important.
Each sheet is a landscape image (ask for 3:2, 1536x1024) with a grid of equal cells. Items are listed in reading order (left to right, top to bottom). Send the file names list to Claude with the PNG so the items get the right names.

## About transparent background
ChatGPT often draws a white or checkerboard background even when you ask for transparent. Do this:
1. Send the prompt as written (it asks for transparent).
2. If the result has a white, grey or checkerboard background, ask in the same chat: **"Redo the same sheet on a flat pure magenta #FF00FF background, same layout, no magenta inside any item."**
3. Save the PNG and give it to Claude. Claude removes the background and cuts the items. (`Tools/slice_sheet.py` expects real transparency. Python must be reinstalled on this PC first.)

## STYLE (already inside every prompt)
Glossy chunky candy-style casual mobile puzzle game icons, thick soft rounded shapes, rich saturated colors, bright top highlight, darker underside, thin dark navy outline, cute and clean. No text, no letters, no numbers, no watermark.
